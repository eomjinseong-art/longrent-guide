# 장기렌트 비교노트

신차 장기렌트·리스·할부 비교 정보 사이트 (Next.js, Vercel).

## 상담 버튼 링크 바꾸기

`lib/config.ts`의 `CTA_URL`에 제휴 상담 랜딩 URL을 넣으면 모든 페이지 하단 상담 버튼이 켜집니다.
비어 있으면 「상담 연결 준비 중」으로 표시되고 링크가 나가지 않습니다. 두 번째 캠페인 URL은 `CTA_URL_NEWCAR`(선택).

검색엔진 소유 확인 코드도 같은 파일의 `NAVER_SITE_VERIFICATION`, `GOOGLE_SITE_VERIFICATION`에 넣습니다.

## 원칙

- 월 비용은 예시 추정치로만 표기, 확정 금액·승인 약속 표현 금지
- 중고차·단기렌트·일시불·슈퍼카 등 상담 불가 대상은 유도하지 않음
- 자체 신청 폼 없음(제휴 랜딩 링크만)
